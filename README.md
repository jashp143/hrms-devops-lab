# hrms-devops-lab

A hands-on DevOps lab: a real multi-service application (Java/Spring Boot, Python/FastAPI, Next.js,
PostgreSQL + pgvector, Valkey, Socket.IO) taken through containers, CI, Kubernetes, GitOps, observability,
Terraform and Ansible.

The application source code is private. This repo holds the infrastructure, the docs and the write-ups.

Start here: [docs/00-ROADMAP.md](docs/00-ROADMAP.md)
